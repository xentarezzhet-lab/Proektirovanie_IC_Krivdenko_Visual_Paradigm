AutoService — проектирование информационной системы

Учебный проект по дисциплине **«Проектирование информационных систем»** (ГУУ, БИ 3-3).
Выполняется по методичке Галиаскарова Э.Г., Воробьёва А.С. «Анализ и проектирование систем с использованием UML», на собственном кейсе — **сеть автосервисов AutoService** (вместо примера «Астрокофе» из учебника).

Предметная область

Сеть автосервисов внедряет систему для:
- записи клиентов на обслуживание,
- ведения истории обслуживания автомобилей,
- программы лояльности (баллы, вознаграждения),
- контроля работы мастеров.

Структура репозитория

| Файл/папка | Содержимое |

| `AutoService.vpp` | Проект Visual Paradigm (все диаграммы по лабам) |
